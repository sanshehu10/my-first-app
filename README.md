# My First App

A very simple beginner web app built with **HTML, CSS, and JavaScript**.

## Features

- Home page with title and short description.
- To-do list where you can:
  - Add items
  - Mark items as complete
  - Delete items
- Clean and simple layout.

## How to run

1. Open a terminal in this project folder.
2. Start a local web server:

   ```bash
   python3 -m http.server 8000
   ```

3. Open your browser and go to:

   ```
   http://localhost:8000
   ```

4. Use the form to add tasks, check the box to mark them complete, and click **Delete** to remove them.

## Project structure

- `index.html` — page structure
- `styles.css` — app styling
- `script.js` — to-do list behavior
